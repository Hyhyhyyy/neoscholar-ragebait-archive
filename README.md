## 我完成了什么

我围绕一个具体问题开展研究：在讨论 ragebait 的 YouTube 长视频中，创作者是否出镜，与评论区第一层评论呈现出的不同话语模式是否存在关联？

研究从 30 个候选视频中人工筛选出 20 个长视频，按主要呈现方式分为 10 个出镜视频和 10 个旁白视频。通过 YouTube Data API 获取 45,544 条原始评论，在排除回复后形成 34,448 条父级评论的分析语料。数据清洗包括 emoji 文本化、非 ASCII 字符处理、换行清理、评论层级识别和视频来源编码。

分析使用 MDCOR 进行主题聚类，并使用 SENA 描述情绪与情感模式。最终选择 14 主题方案，再通过研究者解释把聚类结果转化为可读的话语类型。

## 核心发现

在这组经过筛选的样本中：

- 出镜视频的评论语料更集中于情感化、戏谑、自我卷入和个人经验投射等表达；
- 旁白视频的评论语料更集中于真实性质疑、道德评价、概念反思、反方论证和背景补充；
- 评论区并非只有敌意。愤怒与道德判断确实存在，但怀疑、反思、语境补充和讽刺游戏同样明显；
- ragebait 评论区不仅延续情绪刺激，也可能成为用户解释、质疑、调侃和重新框定争议的公共空间。

这些结论是探索性、描述性的关联，不是对“出镜造成某类评论”的因果证明。更完整的方法、发现和边界见 [研究摘要](RESEARCH_SUMMARY.md)。
